В данной лабораторной работе изучаются основы работы с Git и GitHub. Мы учимся управлять версиями исходного кода проекта. Система Git позволяет фиксировать изменения с помощью коммитов. Использование веток помогает вести разработку изолированно от основного кода. Сервис GitHub предоставляет удобные инструменты для совместной работы и управления задачами.
• Освоена работа с ветками и слиянием изменений
• Изучен процесс разрешения конфликтов при совместной работе.
• Освоены инструменты GitHub Issues и Projects.
